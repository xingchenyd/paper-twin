首次使用：解压后双击启动

  1. 默认电脑已安装 Python 3.11 或更新版本（包含 tkinter）。
  2. 解压助手到自己的固定文件夹。Windows 双击“启动对页.cmd”，在提示框点击“启动对页”，已有依赖直接复用，缺失依赖自动安装；macOS / Linux 在终端运行 sh start.sh。
  3. 在自动打开的本机网页上传论文，选择 WorkBuddy 或 API。以后在同一文件夹启动，历史仍在。
助手已启动，打开本机工作空间 ↗

未启动助手时，本机地址无法打开。本页不连接或读取你的本地文件；处理与阅读在本机网页完成。

选择自己的翻译方式

WorkBuddy：复制网页生成的任务指令，发送到自己的 WorkBuddy，结果通过本机文件自动接收。这是本地桥接，需要主动启动任务。

翻译 API：将助手内的 api-config.example.json 复制为 api-config.json，填写自己的 OpenAI 兼容 API 地址、模型与密钥，在论文的翻译窗口点击“使用 API 翻译”。费用由自己的 API 账户承担。

数据保存在什么地方？

PDF、译文、句子对应关系保存在助手文件夹的 data 目录；阅读页码保存在本机浏览器。备份整个助手文件夹即可保留文库。不要删除 data 目录，也不要每次解压到新文件夹。

公共网站不收集论文，也没有共享文库。翻译时 API 或 WorkBuddy 仍会按其工作方式处理论文文本。共用同一电脑与助手文件夹的人会看到同一个文库。

支持有文本层的 PDF；复杂图表、公式、算法和参考文献可能保留原文，不承诺完全一致的排版。Windows 已测试，其他系统尚未实测。
