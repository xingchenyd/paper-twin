# 对页 · Paper Twin

英文论文 PDF 的本地英中对照阅读与翻译工具。公共网站仅提供安装入口，不处理或保存用户论文。

## 启动

安装 Python 3.11+，Windows 安装时勾选 Add Python to PATH。下载 Releases 中的 paper-twin-local.zip，解压后运行 `安装并启动.cmd`。首次需联网安装依赖。macOS/Linux 可运行 `sh start.sh`（尚未实测）。

本机地址：http://127.0.0.1:8766/ 。关闭网页不会删除文库。助手只监听回环地址，不开放局域网访问。

## 两种翻译方式

- WorkBuddy：上传 PDF，在翻译窗口复制任务给自己的 WorkBuddy。通过本机文件逐页接收译文。不是官方 OAuth 接入，仍需手动启动任务。
- API：复制 `api-config.example.json` 为 `api-config.json`，配置 OpenAI 兼容服务的 base_url（通常以 /v1 结尾）、model、api_key。在论文的 WorkBuddy 桥接窗口点击“使用 API 翻译”。模型调用由用户付费，论文文本发送给所配置服务。失败可重试，已保存片段会跳过。不同供应商兼容性需实际验证。密钥配置不提交到 GitHub。

## 本地历史与备份

`data/` 保存原文、译文、句子坐标和任务文件。每人使用自己的助手文件夹与操作系统账户。公共网站不接收这些文件。浏览器保存阅读页码；换浏览器可能重置页码。备份整个助手文件夹（密钥自行妥善保管）即可保留文库；不要删除 data 或反复换目录启动。

浏览器独立文档存储和可导入项目包尚未实现。本版采用本机服务的文库；无需公网服务器。共用同一助手文件夹的人会共享文库，不具备账号隔离。

## 范围

仅支持可选文本 PDF，最多 150 页 / 60 MB。左右阅读、同步滚动、双向句子高亮、PDF 下载、首页上传、历史搜索与页码恢复。复杂表格、图内英文、公式和参考文献可能保留原文，不能保证全部翻译或完全相同排版。

Python + PyMuPDF 自定义布局实现；参考项目：BabelDOC、PDFMathTranslate-next。未直接集成其翻译引擎。PyMuPDF 使用时请遵守其授权条件。本仓库暂未授予额外开源许可。

## 公网发布

site/ 为纯静态入口，通过 GitHub Pages 发布。GitHub Actions 仅部署静态文件；不运行用户翻译任务，不打包任何 data、密钥、日志或示例论文。安装包只含运行代码和说明。
