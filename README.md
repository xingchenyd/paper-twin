# 对页 · Paper Twin

[打开在线网页](https://xingchenyd.github.io/paper-twin/)

直接在浏览器中上传英文论文 PDF、调用自己的翻译 API、对照阅读并导出中文 PDF。无需 Python、安装包或本地助手。

## 使用

1. 点击翻译设置，填写 OpenAI 兼容 API 基础地址（通常以 /v1 结尾）或完整 /chat/completions 地址、API Key。
2. 点击获取模型并选择。服务不提供 /models 时手动填入模型 ID。只有一个模型时自动填入。
3. 上传有文本层的 PDF，点击开始翻译。中断后可继续未完成片段。
4. 在历史记录重新打开论文，或导出 JSON 备份带到其他浏览器。

API Key 仅保留在当前页面内存，刷新后需重新输入；地址和模型保存在 localStorage。翻译由用户自己的服务计费。

## 接口兼容性

支持 POST /chat/completions，Bearer API Key，非流式返回 choices[0].message.content。需要模型能按提示返回 JSON。模型参数通常必填；不默认猜测模型或更改服务商。

服务必须允许网页来源 https://xingchenyd.github.io 的 CORS 请求，包括无密钥 OPTIONS 预检、Authorization 和 Content-Type 请求头，以及 GET /models 和 POST /chat/completions。若预检返回 401，浏览器不会继续发送实际请求；在页面填写正确密钥也无法绕过。

127.0.0.1 和 localhost 始终指访问者自己的电脑，并不构成公开共享服务。HTTP 回环地址还可能受浏览器本地网络权限限制。免安装使用需选支持浏览器直连的 HTTPS 公网 API。本项目没有隐式转发密钥的公共代理，不保证任意 API 均可连接。

## 数据

原文、译文文本、句子位置和页码保存在 IndexedDB。公共站点不接收论文；翻译文本发送给所填 API。密钥不写入文档备份。存储按浏览器配置和网站来源隔离，共用同一浏览器配置会共用历史。

浏览器清理数据会删除历史，持久化存储申请并非永久保证。请通过导出备份保存完整记录。导出 PDF 只含阅读结果，不含网站高亮交互；JSON 备份可恢复双栏阅读。无跨设备自动同步。原先本地助手的数据仍在自己的 data 文件夹，新网页版不会自动读取本机旧目录。

## PDF 边界

最多 150 页、60 MB，扫描件与旋转页面暂不支持。纯浏览器实现使用 PDF.js 提取正文、估算句子位置，PDF-lib 在原位置叠加中文；复杂图表、数学式、参考文献和无法容纳的译文保留原文。布局受原 PDF 结构影响，不保证任意论文完全一致。超出区域的译文可在句子卡片查看。

中文导出保留原始页面图像和矢量内容，并嵌入 Noto 中文字体。白色覆盖仅用于视觉排版，原文字仍可能保留在 PDF 底层，不是保密涂黑工具。

## 开发与部署

site/ 是完整静态网站。GitHub Actions 发布该目录到 GitHub Pages，不需要服务端运行时或域名购买。依赖版本记录在 package-lock.json。site/vendor 包含 PDF.js、PDF-lib、fontkit 和 Noto Sans CJK SC 字体及相应许可证，避免运行时从第三方 CDN 下载脚本。

旧的本地助手版本保留在历史 Git 标签中，已不再作为网页使用入口。历史个人论文与译文未发布到仓库。

## 分栏修复（0.3.2）

按栏间距分离同一高度的正文，连接段内换行和行尾断词。旧记录首次打开时自动重新解析，只复用原文完全匹配的译文，其他片段可继续翻译；旧排版保留在备份数据中。503 区分代理无可用账号、冷却与任务占用，已完成译文不会丢失。

## 后台翻译与排版（0.4.0）

翻译请求和逐批保存由独立 Web Worker 执行，不再等待 PDF 画布重绘。正常切换标签页或其他程序可以继续翻译；关闭页面、浏览器冻结/丢弃标签页或电脑睡眠仍会中断，可从历史继续。默认并发 2 批，每批最多 20 个片段、约 6000 字符，可在设置中将并发调为 1–4；限流时降为 1。出错或停止时保留已保存批次，实际速度由 API 决定。

解析器 v3 使用跨行重复空隙识别栏界，区分实际字号和字体包围盒，并还原行末断词。旧记录自动重新解析并保留可精确匹配的译文。已使用用户报告的 28 页双栏论文验证引言分栏及 transport/effectively 断词，并在禁用动画帧的浏览器测试中验证后台翻译和保存。纯浏览器规则仍无法保证所有复杂版式；参考的 [BabelDOC](https://github.com/funstory-ai/BabelDOC) 是 Python 工具，未将其服务端依赖嵌入此静态网页。

## 即时局部翻译（0.5.0）

阅读页支持双击英文单词、点击已识别句子，以及点击“段落框选”后在左页拖出矩形。三种操作都调用用户配置的 API；单词会附带所在句子作为消歧上下文，句子和段落结果会逐句写回本地记录，可继续对照阅读与导出 PDF。新的选择会取消尚未完成的上一次局部请求，全文后台翻译不受画布重绘影响。
